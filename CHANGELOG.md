# Changelog

## 1.0.0

First published release of the Rust application. Earlier 3.x numbers were local
development builds; their history remains in Git.

- Windows dictation through the OpenAI API or an optional ChatGPT browser extension.
- Editable, persistent global shortcuts; paste or clipboard-only output.
- A 64 px dockable microphone badge and a status window that opens beside it.
- Persistent volume and Original / Mouth sound packs, with a soft writing cue.
- Ordered background sound playback, error logging, and session-safe text delivery.
- A self-contained Windows ZIP with setup scripts and the optional extension.
- Removed retired Python applications, old executables and temporary development files.
